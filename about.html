📊 江浙沪天气监测与农业影响系统

一个完全自动化的天气数据分析平台，每日更新，展示过去30天天气分布、温度趋势、湿度与降雨关系，并提供未来7天温度/湿度预测。同时集成实时气温地图，针对江浙沪25个城市给出基于温度的农业种植建议。

📁 数据来源

  • Open-Meteo 开源气象 API

🛠️ 技术栈与库

Python 3.10 Pandas NumPy Plotly statsmodels pmdarima (auto_arima) SARIMAX Flask Leaflet 高德地图底图 GitHub Actions
  • 数据处理：Pandas 进行数据清洗、特征工程（平均温度、温差、天气简化、滞后变量）。
  • 可视化：Plotly 绘制交互式图表（饼图、折线图、柱状图、双轴图、预测图）。
  • 时间序列建模：
    • 温度预测：ARIMA(2,1,3)。
    • 相对湿度预测：SARIMAX(2,1,1) 引入外生变量（风速、降水量、晴天/雨天标志、前一天最高温），模型显著变量解释力强。
  • 后端API：Flask API（部署于 PythonAnywhere）并发获取 25 个城市实时天气数据；前端使用 Leaflet + 高德底图。
  • 自动化部署：GitHub Actions 每日定时执行脚本，生成静态 HTML，部署至 GitHub Pages / PythonAnywhere。

📈 分析内容与业务价值

  • 过去30天天气分布：直观显示最近一个月的常见天气类型及占比，辅助农业安排（如雨天多注意排水）。
  • 过去30天温度趋势：展示最高/最低温变化，标注温差区间，提示极端温度事件。
  • 过去7天天气变化：每日最高/最低温及天气符号，方便快速了解短期波动。
  • 湿度与降雨：揭示降水与湿度的正相关关系，辅助判断霉变或灌溉需求。
  • 未来7天最低温预测：基于历史最低温序列的 ARIMA 预测，带95%置信区间，便于防霜冻准备。
  • 未来7天相对湿度预测：SARIMAX 模型利用外生变量（降水、风速、晴雨、昨日高温）给出更精准的湿度预测，并提供变量影响解释（例如：雨天湿度平均高4.8%，晴天低3.2%）。
  • 实时气温地图：Leaflet + 高德底图，展示25个城市实时温度，点击弹出农业建议（依据温度区间及当地主要作物：水稻、茶叶、柑橘、棉花等）。

🎯 业务落地：所有温度区间的划分参考农业气象标准，直接给出可操作提示（如“午后遮阳”“增加灌溉”），助力种植决策。
